This module provides a gateway integration between Odoo Discuss and Zulip, allowing bidirectional message synchronization between the two platforms.

Features
========

* Bidirectional message synchronization between Odoo Discuss and Zulip
* Support for Zulip streams and topics
* Automatic channel creation for new Zulip streams/topics
* User mapping between Zulip users and Odoo partners/guests
* Message editing synchronization
* Webhook-based real-time updates
* Stream and topic filtering options

Configuration
=============

Zulip Setup
-----------

1. In your Zulip organization, create a new bot:
   
   * Go to Settings → Your bots
   * Click "Add a new bot"
   * Choose "Generic bot" type
   * Set a name and email for the bot
   * Copy the API key

2. Configure webhook (optional):
   
   * Go to Settings → Integrations
   * Find "Webhook" integration
   * Set the webhook URL to: ``https://your-odoo-domain.com/gateway/zulip/YOUR_WEBHOOK_KEY/update``

Odoo Setup
----------

1. Install the ``mail_gateway_zulip`` module

2. Go to Discuss → Configuration → Mail Gateways

3. Create a new gateway with the following settings:
   
   * **Name**: Choose a descriptive name (e.g., "Company Zulip")
   * **Gateway Type**: Select "Zulip"
   * **Token**: Generate a unique token for this gateway
   * **Webhook Key**: Generate a unique webhook key
   * **Webhook Secret**: Optional security token
   * **Zulip Server URL**: Your Zulip server URL (e.g., ``https://your-org.zulipchat.com``)
   * **Bot Email**: The email address of your Zulip bot
   * **API Key**: The API key from your Zulip bot
   * **Stream Filter**: Comma-separated list of streams to monitor (leave empty for all)
   * **Topic Filter**: Comma-separated list of topics to monitor (leave empty for all)

4. Add team members to the gateway to give them access to Zulip channels

5. Click "Set Webhook" to activate the integration

Usage
=====

Channel Creation
----------------

* Channels are automatically created when messages are received from new Zulip streams/topics
* Channel names follow the format: "Zulip: {stream_name} / {topic_name}"
* Existing Odoo users are automatically linked if their email matches a Zulip user
* Unknown Zulip users are created as guests in Odoo

Message Synchronization
-----------------------

* **From Zulip to Odoo**: Messages posted in monitored Zulip streams/topics appear in corresponding Odoo channels
* **From Odoo to Zulip**: Messages posted in Zulip gateway channels are sent to the corresponding Zulip stream/topic
* Message editing is synchronized in both directions
* Simple text formatting is preserved

Filtering
---------

Use the filter options to control which Zulip content is synchronized:

* **Stream Filter**: Only monitor specific streams (e.g., "general,development,support")
* **Topic Filter**: Only monitor specific topics across all streams (e.g., "announcements,urgent")
* Leave filters empty to monitor all streams/topics
