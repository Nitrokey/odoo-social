Mail Zulip Gateway

Bridge Odoo Discuss and Zulip

Features

  • Bidirectional message synchronization
  • Support for Zulip streams and topics
  • Automatic channel creation
  • User mapping between platforms
  • Real-time webhook updates
  • Stream and topic filtering

How it works

The Zulip Gateway creates a seamless bridge between your Odoo Discuss channels and Zulip streams/topics. Messages flow bidirectionally, keeping your teams connected across both platforms.

Configuration

Zulip Setup

  1. Create a bot in your Zulip organization
  2. Copy the bot's API key
  3. Configure webhook URL (optional)

Odoo Setup

  1. Install the mail_gateway_zulip module
  2. Go to Settings → Technical → Email → Gateway
  3. Create a new Mail Gateway with type "Zulip"
  4. Configure Zulip connection details
  5. Set up stream/topic filters
  6. Activate the webhook
